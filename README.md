# Finanzplanung

Persönlicher Finanzplaner (Rente, Vermögen, Abfindung, Szenarien) als eine einzelne Webseite. Alles wird im Browser gerechnet.

- Keine Zahlen im Repository: Eingaben bleiben im Browser oder in einer selbst gespeicherten `finanzplanung.json` (Speichern/Laden in der Seite).
- Die Datei `finanzplanung.json` gehört nicht ins Repository.
- Aufbau: `index.html` (Seite mit Rechenlogik), `site.css`, `styles.css`, Icons, `manifest.json`.
- Chart.js wird von cdnjs geladen.
